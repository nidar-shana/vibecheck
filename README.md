# vibecheck
Hourly Push Notifications on the phone for checking in on one's physical and mental well-being.

The Idea is to make a person, especially an introvert, feel like they belong somewhere. In this digital era where it's easy to lack a real connection, something checking up on you makes one feel less lonely.
Hoping this idea executes well! :)

## Setup / Installation Guide:
git clone https://github.com/nidar-shana/vibecheck.git
cd vibecheck
npm install
npm start
